<h2>📦 Sobre o Projeto/<em>About the project</em></h2>

<p>
O jogo simula um ambiente de plataforma entre dois jogadores controlando reis
que se movem, desviam e atiram projéteis em porquinhos.  
A lógica foi implementada totalmente em C++ com boas práticas em OOP, como por exemplo:

<em> The game simulates a platform environment with 2 players controlling kings 
that move, dodge and shoot projectiles at Pigs.
The game was only built with C++ and good uses of OOP, for example:</em>
</p>

- Player  
- Projectile  
- Collision System  
- Game Loop  
- Render Window (SFML)

<p>
Este projeto teve como objetivo reforçar fundamentos de <strong>orientação a objetos</strong>, 
controle de estado, encapsulamento, modularização e práticas de organização de código.

<em>This project had the objective to reinforce the fundamentals of OOP programming, 
such as state control, encapsulation, modularization and good practices of clean code</em>
</p>
