# PigsCpp
 Projeto de Jogo, Utilizando a biblioteca visual SFML 3.0.0 e mecanismos de orientação a objetos em C++ 2003 e engenharia de software em seu desenvolvimento, realizado como trabalho a ser entregue à disciplina Técnicas de Programação na UTFPR Curitiba.
_Game application, using the visual framework SFML 3.0.0 and mechanics of oriented object programming in C++ 2003 and software engineering for development, made as a project to be assigned for the subject Programming Techniques in UTFPR Curitiba._

Documentação do projeto (Everything in PT-BR): https://drive.google.com/drive/folders/1twPns8ZqGgOIWkFjNrcrHcZ0cV404VwE?usp=drive_link

===== Controles =====

Jogador 1: WASD para se mover, E para atirar projétil.
Jogador 2: Setinhas para se mover, ESPAÇO para atirar projétil.

_===== Controls =====_

_Player 1: WASD for moving, E to shoot projectile._
_Player 2: Arrows for moving, SPACE to shoot projectile._
